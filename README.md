
# 💰 MyKhata – Expense Management Application

MyKhata is a simple and user-friendly expense management web application built using HTML, CSS, and JavaScript. It helps users manage their daily income and expenses, track their balance, and keep their financial records organized in one place.

## 📌 Project Overview

The main purpose of MyKhata is to make daily money management easier. Users can add their income and expenses, view their transaction history, and check their available balance through an interactive dashboard.

## ✨ Features

- Add new income and expense transactions.
- Delete existing transactions.
- Calculate total income and expenses.
- Display available balance.
- View transaction history.
- Interactive dashboard with charts.
- Clean and modern user interface.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – For website structure.
- **CSS3** – For styling, layout, and responsive design.
- **JavaScript** – For functionality and interactivity.
- **Local Storage** – For saving transaction data (if implemented).

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all files are in the correct folder.
4. Open `index.html` in your browser.
5. You can also use the Live Server extension in VS Code.
